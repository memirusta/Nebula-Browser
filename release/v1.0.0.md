# Nebula v1.0.0 — First Stable Release

Nebula is officially leaving beta. This release focuses on stability, security,
performance, and a polished Windows browsing experience.

## Highlights

- Synchronized Semi-Lunar navigation between browsing and the home screen.
- Fixed tab closing, switching, last-tab handling, and native WebView crashes.
- Fixed fullscreen video, Windows taskbar, maximize, and restore behavior.
- Neutralized visible embedded browser runtime branding.
- Added custom in-app error pages for failed connections.

## Security and privacy

- Protected the password vault with Windows DPAPI encryption.
- Hardened password autofill and save behavior.
- Migrated Google OAuth to Authorization Code with PKCE.
- Tightened capabilities, CSP rules, WebView settings, and production tooling.

## Performance

- Reduced memory usage for inactive tabs.
- Reduced CPU usage from system-stat and metadata polling.
- Removed unused dependencies and unnecessary background work.
- Added lazy loading and optimized Rust release settings.
