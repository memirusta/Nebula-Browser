Nebula 1.8 is a major update focused on a more flexible, persistent, and Windows-integrated browsing experience.

## Highlights

- Added multi-window support, including moving tabs between Nebula windows.
- Added native screen and window sharing.
- Pinned shortcuts now persist between sessions.
- Tab back and forward navigation history is now preserved.
- Downloads remain available after their originating tab is closed.
- Added a centralized notification center for website notifications.
- Improved integration with Windows media controls.
- Added adaptive webpage darkening.

## Improvements and fixes

- Introduced Nebula's new application, installer, Windows, Store, and desktop shortcut icons.
- Ctrl+L now focuses the address bar and selects its contents.
- Improved history search relevance.
- Fixed history panel theme synchronization.
- Prevented site menus and information panels from extending beyond the viewport.
- Improved stability around error pages and native communication.
- General performance and reliability improvements.

## Privacy

Nebula's built-in ad and tracker blocking, privacy controls, cookie management, and secure browsing features remain fully supported.

> Note: Screen sharing availability for some fullscreen games may depend on the game's display mode and Windows capture support.

Thank you for using Nebula. 🌙
