# Nebula v1.8.2

Nebula 1.8.2 focuses on stability, fullscreen behavior, visual consistency, and fixes across Semi-Lunar, site metadata, widgets, and multi-window browsing.

- Fixed Semi-Lunar folders not accepting multiple shortcuts from the same domain when their URL paths differ.
- Fixed Semi-Lunar context-menu and layout corruption when right-clicking the same shortcut again while its context menu is already open.
- Improved Auto Darken compatibility on sites that were previously only partially darkened or rendered incorrectly.
- Fixed incorrect favicon selection, including Gmail and other sites incorrectly falling back to Google branding.
- Improved site icon quality by preferring higher-resolution favicon sources and avoiding blurry upscaling.
- Connected RAM, CPU, and other widget header indicators to Nebula's selected accent color.
- Updated the Network widget status indicator to show green while online and red while offline.
- Fixed window isolation so a window opened with Ctrl+N is no longer affected by shortcut or site actions performed in another Nebula window.
- Improved HTML5 fullscreen handling across video players, preserving fullscreen correctly through Alt+Tab and preventing broken window, taskbar, or persistent-fallback states.
- Improved F11, fullscreen, and Semi-Lunar window state transitions.s
